Политика конфиденциальности приложения «Комната VAR»

Дата публикации: 13.10.2026

Оператор приложения «Комната VAR»: Пономарев Максим Русланович.

Контакт по вопросам данных: clon3444@gmail.com.

Почтовый адрес: не применяется.

2. Какие данные обрабатывает приложение

Приложение не создаёт учётную запись, не передаёт ник или игровой прогресс на сервер разработчика и не использует аналитические или рекламные SDK.

Приложение хранит только на устройстве пользователя:

  • выбранный пользователем ник;
  • очки, уровень, ответы, серию и достижения;
  • дату последнего прохождения;

Эти данные нужны только для работы локального игрового прогресса и не покидают устройство через приложение.

3. Внешние сайты и реклама

Приложение не использует рекламные или аналитические SDK, не содержит рекламы и не открывает партнёрские или рекламные сайты. Единственный внешний переход — публичная страница этой политики конфиденциальности, которую пользователь может открыть из экрана профиля.

4. Удаление данных

Пользователь может удалить все локальные данные в приложении: Профиль и коллекция → Удалить локальные данные → Удалить данные.

После подтверждения удаляются ник и игровой прогресс. Восстановить эти данные через приложение невозможно, так как серверная копия не создаётся.

5. Срок хранения и безопасность

Локальные данные хранятся до их удаления пользователем, очистки данных приложения в настройках Android или удаления приложения. Приложение не запрашивает опасных разрешений Android и не использует незашифрованные сетевые соединения.

6. Изменения политики

При изменении способов обработки данных новая версия политики будет опубликована по этому же адресу с обновлённой датой.

7. Обращения
